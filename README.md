# Funciones a bordo

Graficador de funciones 3D con modo WebXR para Meta Quest 3.

## Idiomas

La interfaz, el tablero de VR y la narración están en español, inglés y portugués.
El idioma se elige con el selector de la cabecera y queda guardado en el navegador.
También se puede fijar en la dirección: `index.html?lang=en`, `?lang=pt` o `?lang=es`.

Los textos se escriben en español en el código; la función `_T()` los traduce con el diccionario `I18N`.
